# ЛР1 — Marketplace Claim Fraud Detection

## Предметная область

Датасет содержит обращения пользователей маркетплейса на возврат или компенсацию.

Цель: предсказать `is_fraud`, где `0` — обычное обращение, `1` — fraudulent claim.

## Файлы

### train.csv

Содержит подготовленные признаки и target `is_fraud`.

### test.csv

Содержит те же признаки, что и `train.csv`, но без target. Данные `test.csv` предназначены для финальной проверки модели.

## Группы признаков

- `claim_id`: технический идентификатор строки. Не должен использоваться как признак при обучении модели.
- `account_age_days`: возраст аккаунта пользователя на момент текущего обращения.
- `orders_before_claim`: количество заказов пользователя до текущего обращения.
- `claims_before_claim`: количество предыдущих обращений пользователя.
- `returns_before_claim`: количество предыдущих возвратных обращений пользователя.
- `successful_orders_before_claim`: количество заказов до текущего обращения без claim.
- `total_spent_before_claim`: суммарная стоимость предыдущих заказов пользователя.
- `average_order_amount_before_claim`: средняя стоимость предыдущих заказов пользователя.
- `average_claim_amount_before_claim`: средняя запрошенная сумма по предыдущим обращениям.
- `claim_rate_before_claim`: доля предыдущих заказов пользователя, по которым создавались claims.
- `days_since_previous_order`: дней с предыдущего заказа пользователя.
- `days_since_previous_claim`: дней с предыдущего обращения пользователя.
- `claims_last_7_days`: количество предыдущих claims за 7 дней до текущего обращения.
- `claims_last_30_days`: количество предыдущих claims за 30 дней до текущего обращения.
- `orders_last_30_days`: количество заказов за 30 дней до текущего обращения.
- `category`: категория товара в текущем заказе.
- `order_amount`: стоимость текущего заказа.
- `delivery_type`: тип доставки текущего заказа.
- `payment_type`: тип оплаты текущего заказа.
- `seller_rating`: рейтинг продавца текущего заказа.
- `days_from_order_to_delivery`: сколько дней прошло от заказа до доставки.
- `days_from_delivery_to_claim`: сколько дней прошло от доставки до обращения.
- `order_amount_vs_user_average`: отношение стоимости текущего заказа к обычной стоимости заказов пользователя.
- `reason`: причина обращения.
- `requested_refund_amount`: запрошенная сумма возврата.
- `refund_ratio`: отношение запрошенной суммы возврата к стоимости заказа.
- `has_photo`: приложена ли фотография к обращению.
- `has_video`: приложено ли видео к обращению.
- `verified`: верифицирован ли аккаунт пользователя.

## Важные замечания

1. Все historical признаки рассчитаны только по данным, существовавшим ДО текущего claim.
2. Будущая информация при подготовке признаков не использовалась.
3. В датасете присутствует class imbalance.
4. `claim_id` нельзя использовать как ML-признак.
5. Не следует считать Accuracy единственной метрикой качества.
6. Данные `test.csv` предназначены для финальной проверки модели.
